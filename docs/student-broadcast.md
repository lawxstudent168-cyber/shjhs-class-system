# 學生手機廣播：身分綁定與收件匣

導師直接依座號、姓名選個別學生或全班發送文字與短提示音。不再申請裝置、人工核准、核對碼或每 15 分鐘重新開始收聽。

本分支從 `abedul59/shjhs-class-system` 的 `c788f35` 建立，只加入個人首頁及學生手機廣播，不含備份分支的導師今日待辦。教室廣播仍獨立運作。

## 升級部署

1. 在存放學生資料的同一 Supabase 專案確認 `student_broadcast_clients`、`student_broadcast_inbox` 是否存在。如果先前已為舊分支執行過 `202609230002_student_broadcast_inbox.sql`，不要重跑；若尚未執行，才在 SQL Editor 執行 `supabase/migrations/202609230002_student_broadcast_inbox.sql` 一次。這兩表啟用 RLS，anon/authenticated 不可直接讀寫；不要新增公開 policy。
2. 在部署此分支的 Vercel 專案設定伺服器環境變數：`NUXT_PERSONAL_HOME_SECRET`、`NUXT_STUDENT_BROADCAST_SUPABASE_URL`、`NUXT_STUDENT_BROADCAST_SERVICE_KEY`。若該 Vercel 專案已設定，沿用即可；不需新增登入密碼或管理金鑰。
3. 合併並重新部署。導師登入方式沿用現有設定，登入後直接管理廣播。
4. 學生到「個人首頁」選學生身分驗證一次，即自動綁定瀏覽器。舊版的裝置核准不會自動轉成新版綁定；已登入的舊使用者也需重新驗證一次。

新版不讀寫舊 `student_broadcast_devices` 表，舊資料保留以便回復，不必刪除。新安裝只需本次 002 SQL，無須先建旧版 001 表。請先執行 SQL 再部署程式，缺表時廣播會停止，個人首頁仍可使用。

## 導師操作

開啟「遠端廣播與定時」中的學生廣播區，會自動列出全班座號、姓名、有效綁定瀏覽器數與最近連線時間。選取學生或勾全班，輸入最多 200 字後發送。沒有瀏覽器綁定的學生也可以收件，待首次驗證後補收。

送出成功表示收件匣已保存，不代表學生已讀或聽見。最近連線是最近一次輪詢時間，不是手機即時在線保證。單一批次使用固定 request ID，相同內容在網路錯誤後按重試不會重複寄送；修改內容或對象代表新的發送。

## 學生操作

首次以個人首頁的學生驗證流程確認座號、生日與身分證後五碼後，伺服器建立 90 天的瀏覽器綁定；只在 HttpOnly、SameSite=Strict cookie 保存隨機憑證，資料庫保存其雜湊。網頁關閉後再開啟同一網域，仍會辨識該學生，不必每天重新綁定。清除 cookie、換瀏覽器、無痕模式或到期後需重新驗證。

網站各頁的右下角會顯示學生廣播面板。前景每 5 秒檢查新訊息，未讀訊息保留 24 小時，下次開啟自動補收，過期不再顯示。一次顯示最早 50 則，標記已讀後會載入其餘未讀。已讀狀態以學生為單位，在該學生的其他瀏覽器也會同步消失。

文字不需要任何開始收聽操作。聲音需依瀏覽器限制按「啟用新通知提示音」；只提示啟用後即時到達的新訊息，補收舊訊息不補播聲音。重新載入、切到背景或離線後可能需重新啟用聲音。沒有麥克風直播、朗讀、鎖屏播放或系統推播。

「解除此瀏覽器綁定」只解除廣播，不登出個人首頁；解除後不會偷偷自動綁回。重新以學生身分驗證才恢復。

## 身分切換與範圍

- 個人首頁登出、切換學生、改以家長登入時，清除原瀏覽器 cookie 並撤銷舊憑證。其他同源分頁也會停止音訊、清除訊息；逾時回應不會恢復旧身分的通知。
- 進入家長私訊／家長綁定／請假頁時會停止接收並解除廣播綁定。舊首頁的身分切換也解除綁定；僅在 localStorage 寫姓名不會取得廣播權限。
- 綁定依網域及瀏覽器而定。多個 Vercel 網域共用 Supabase 時共用學生收件匣，各網域仍須各自驗證。為避免同一學生在多個瀏覽器同時提示，使用完共用設備請解除綁定。
- 系統辨識學生身分，不辨識手機所有權。家長若用學生身分驗證，也會建立學生綁定，不能保證物理上的家長手機永遠無聲。
- 既有教室廣播不使用這兩張新表；本次未全面改造舊網站的其他權限。

廣播資料庫暫時不可用時會停止音訊並重試，不顯示成功假象。登出或家長驗證時即使資料庫撤銷失敗，仍清除目前瀏覽器憑證，家長 session 亦被伺服器拒絕。已外洩的憑證需要資料庫恢復後撤銷或等待到期；正常操作請勿分享 cookie。

過期訊息不再提供，但仍保存在資料庫；可依校方保存政策定期刪除過期收件與失效綁定。每 5 秒輪詢會產生 Vercel/Supabase 用量。

## 驗收與測試

本機：`npm run build`，`node --test tests/*.test.js tests/personalHome.integration.mjs tests/studentBroadcast.integration.mjs`。測試使用本機假 PostgREST，沒有正式 Supabase 寫入。

涵蓋首次驗證自動綁定、90 天 cookie、離線先送後收、全班完整名單分頁、批次重試不重複、學生間隔離、跨瀏覽器已讀、家長切換撤銷、登出／解除、過期排除、音訊手勢與晚回應丟棄。上線前另用 iPhone Safari、Android Chrome 實測瀏覽器聲音行為與背景切換。
