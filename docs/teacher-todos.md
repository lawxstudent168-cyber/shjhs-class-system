# 導師今日待辦

導師解鎖 `/admin` 後預設顯示今日待辦，也可由「☀️ 今日待辦」返回。

- 未讀請假通知：家長頻道中，以系統請假通知標記開頭、尚未讀取的訊息。
- 其他未讀訊息：其餘未讀的家長／學生訊息，不包含導師回覆。
- 逾期未交作業：以台北日期判斷截止日早於今天，且目前學生名單中仍有人未交。今天到期、沒有截止日及已全數繳交的作業不列入。
- 作業卡片顯示未交人數、可展開學生名單，並連到指定作業；仍使用作業頁既有身分驗證。
- 閱讀對話沿用既有已讀流程；已讀不代表請假核准或已回覆。請假不會自動改動出缺席。
- 不寄送家長通知的作業仍出現在導師待辦，不會從此頁寄送任何通知。
- 包含以前尚未處理的項目。返回此頁或點擊重新整理會更新資料。

此版本沿用既有資料表，無需資料庫 migration。所有查詢分頁讀取，載入失敗會顯示錯誤及重試，不會誤顯示零筆待辦。

## 驗證

```sh
node --test tests/teacherTodos.test.js
npm run build
```

實際環境需使用既有 Supabase 設定與權限。上線前以測試帳號確認：

1. 導師後台解鎖後先顯示今日待辦，未解鎖時不載入待辦資料。
2. 未讀請假與一般訊息不重複計數；開啟對應對話後返回，已讀項目消失。
3. 昨天到期的作業顯示未交名單，今天到期的作業不算逾期。
4. 作業連結登入後選中指定作業，補交後返回今日待辦可見更新。
5. 斷線重新整理顯示錯誤，恢復連線後重試成功；手機寬度不橫向溢出。

限制：本次本機建置未連接正式 Supabase，正式資料與權限仍需在部署環境驗證。現有帳號驗證機制未在本功能中改造。
